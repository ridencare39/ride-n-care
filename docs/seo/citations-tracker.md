## How to update this tracker

1. Before submitting: fill Category/Service Area, set `In progress`.
2. After submission: set `Submitted` + date in Notes.
3. After the platform confirms (live listing visible at a real URL): fill **URL**, set `Verified`,
   run the NAP check against the entity audit, set **NAP Checked** = yes/no + fix date.
4. Any listing showing a wrong phone (especially the WhatsApp number in a call field) or wrong
   name: `Needs correction` + one line on what to fix.
5. Quarterly: re-verify all `Verified` rows for name/phone drift.
